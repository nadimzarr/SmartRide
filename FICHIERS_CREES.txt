================================================================================
                            DÉPANNAGE RAPIDE
================================================================================

❌ Les e-mails ne s'envoient pas?
   1. Vérifiez le cache: php bin/console cache:clear
   2. Testez: php bin/console app:test-email test@example.com
   3. Consultez les logs: tail -f var/log/dev.log

❌ Erreur "SMTP connection refused"?
   1. Vérifiez le mot de passe d'application Gmail
   2. Vérifiez que l'authentification 2FA est activée
   3. Vérifiez que le port 587 est accessible

❌ Les e-mails vont dans le dossier Spam?
   1. Vérifiez l'adresse "From" dans le code
   2. En production, utilisez un domaine personnalisé
   3. Ajoutez des headers SPF/DKIM

================================================================================
                          AVANT vs APRÈS
================================================================================

AVANT (Asynchrone - Bloqué):
   Utilisateur → Request → E-mail en queue → Worker Messenger → Gmail SMTP
   Latence: Quelques secondes
   Worker: Nécessaire

APRÈS (Synchrone - Immédiat):
   Utilisateur → Request → Gmail SMTP (immédiat)
   Latence: Immédiat
   Worker: Non nécessaire

================================================================================
                            NOTES IMPORTANTES
================================================================================

⚠️ SÉCURITÉ:
   • Ne pas commiter .env.local
   • Ne pas utiliser Gmail en production
   • Utiliser un service d'e-mail professionnel en production

⚠️ PERFORMANCE:
   • Mode synchrone: Bloque la requête pendant l'envoi
   • Mode asynchrone: Meilleur pour la performance
   • Utiliser le mode synchrone en développement uniquement

⚠️ FIABILITÉ:
   • Mode synchrone: Pas de retry automatique
   • Mode asynchrone: Retry automatique
   • En production, utiliser le mode asynchrone
